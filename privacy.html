What this page covers

This policy describes the 1stTab bookmark manager, including the localized update notice in version 2.2.2, optional Google Drive backup and restore introduced in version 2.2.1, and this product website. The website and extension are separate: this website cannot read or change your Chrome bookmarks.

Your bookmark library

1stTab reads and edits your native Chrome bookmarks when you use its library. It reads the current page title and URL following your action on the extension’s toolbar icon.

Bookmark notes, tags, favorites, preferences, migration snapshots, recovery backups, and the version-specific dismissal state for update notices are stored in the extension’s local storage on your device. Ordinary local use does not upload your library or collect analytics. Google receives bookmark data only if you explicitly connect Drive and start a backup, as described below. 1stTab does not send bookmark data to AI providers.

Chrome sync & external links

Chrome may sync native bookmarks according to your browser settings. 1stTab notes, tags, favorites, and preferences do not automatically follow that sync. Opening a bookmark connects your browser to its website under that website’s policies.

Starter sites use bundled high-resolution icons. Other bookmark icons request a higher-resolution favicon from Chrome’s saved icons. If no saved icon is available, the extension requests /favicon.ico from the bookmarked website without sending a referrer, bookmark notes, or tags. If loading fails, a first letter is shown.

Your controls

You can edit or delete bookmarks, export a copy, and import an export. Exported files contain saved URLs, tags, and notes; choose where to store or share them. Imports add data and may create duplicates.

Uninstalling removes the extension’s local storage but leaves native Chrome bookmarks. Export your local metadata first if you want to keep it. Migration preserves legacy metadata locally for recovery. Extension exports exclude API keys and authentication tokens.

Extension permissions

  • bookmarks: read and edit the native bookmark library.
  • storage: keep local metadata, preferences, recovery data, and update-notice dismissal state.
  • sidePanel: show the bookmark manager while you browse.
  • activeTab: read the current page after your toolbar click.
  • favicon: display Chrome’s saved website icons for bookmarks, with a first-letter fallback.

Google identity and https://www.googleapis.com/* access are optional. They are requested only if you choose to connect Google Drive; Drive backup uses only the drive.appdata scope. The extension does not request Gmail, Calendar, general Drive-file access, browsing-history permission, or hardware-monitoring permission.

Optional Google Drive backup

Connecting Drive and starting a backup sends Google a versioned export containing bookmarks, folders, notes, tags, favorites, and supported appearance/view preferences. The export is stored in Drive’s app-private appDataFolder, which is hidden from the normal Drive file list and accessible to this app. Uploads are user-started. Restore is additive, shows a preview, and may create duplicate bookmarks; it does not overwrite existing bookmarks.

The Drive account identifier and display name/email are used to verify the connected account and are stored locally with operation status and timestamps. These account details are excluded from exports. Chrome’s identity API handles access tokens; 1stTab does not log or export tokens. Disconnecting clears local connection details and Chrome’s cached tokens but does not delete backups already in Drive. You can delete backups in 1stTab or revoke the grant through Google account settings. Google deletes the app-private data folder if you uninstall the app from Drive. See Google’s privacy policy.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

This website & feedback

The v2 marketing pages use local assets and do not add analytics, advertising trackers, or a bookmark connection. Preview images contain sample bookmarks. Your browser sends normal page requests to the website’s hosting provider to load the site.

The feedback forms prepare an email draft in your browser. They do not submit information to a form service. Text is sent only if you choose to send it using your email provider. The site does not store drafts in local storage or send them to a server. Messages you send to support are used to respond to your request. Public GitHub issues are visible to others; avoid including private bookmark data or credentials.

What is not included

Version 2.2.1 provides manual backup and restore, not scheduled uploads or continuous sync across devices or Google accounts. Those features are not active. Native Chrome bookmarks may sync according to your own Chrome settings; 1stTab notes, tags, favorites, and preferences do not automatically follow that sync.

Questions about your data
