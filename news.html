Latest Release

v1.0 — Initial Launch

May 6, 2026 · Chrome Web Store

Install Now

The first public release of 1stTab. Built in a weekend, shipped to the Chrome Web Store with bookmarks, world clocks, weather, and eight arcade themes. Everything stored in localStorage, React 18 + Babel, Manifest V2.

Dashboard

  • Two-column widget layout
  • Drag-and-drop widget reordering
  • Custom greeting with your display name
  • Google search bar in the top bar
  • Background picker — 6 built-in gradients + upload your own (up to 5)
  • Settings dialog for theme, background, profile, and weather

Bookmarks

  • Visual grid with favicon icons
  • List view toggle
  • Folder tabs for organisation
  • Pinned strip for quick-access shortcuts
  • Live filter / search
  • Separate Bookmarks Manager page — tree view, drag-reorder, import/export JSON

Widgets

  • World Clocks — local time + up to 3 additional time zones
  • Weather — current conditions + 5-day forecast, °C/°F toggle (Open-Meteo)

Themes

  • Material Light
  • Material Dark
  • Arcade Mode — 8 retro cabinet palettes with CRT scanline effect: Synthwave, Pac-Maze, Game Boy, Galaga, Tron, Hot Lava, Space Invaders, Donkey Kong

Technical

  • Chrome Manifest V2 (migrated to V3 the following day)
  • React 18 + Babel, all data in localStorage
  • Dedicated pages: Bookmarks Manager, Settings

More on the way — tell me what you want.
