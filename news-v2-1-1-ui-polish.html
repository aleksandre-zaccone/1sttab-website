VERSION 2.1.1 · UI POLISH & BUG FIXES

A cleaner library.
A smoother everyday experience.

Sharper icons.
Smaller cards.
Less clutter.

1stTab 2.1.1 brings UI polish and bug fixes to the bookmark library, with clearer website icons, more compact cards, and simpler library tools.

Your favorites, ready when you open a tab

The library now opens to Favorites in grid view. The number of cards per row adapts to the available space, so your favorite links fit comfortably on both wide and small screens. Collections stay within reach in the sidebar.

Sharper icons and smaller shapes

Website icons are now 64 × 64 pixels in card view. Most starter sites use bundled high-resolution icons, while other bookmarks request a larger saved favicon from Chrome. When an icon is unavailable, the first letter of the bookmark name appears.

Circle and Sphere cards are smaller and simpler: the icon comes first, the name sits underneath, and the favorite star is below it. Extra notes, tags, and controls no longer crowd these compact shapes.

Clearer folders and library tools

Folder dropdowns show the hierarchy, making it easier to choose the right destination when folders have similar names. Settings uses clearer labels: Import for bringing in a saved library and Clean duplicates for reviewing repeated links and empty folders.

Export and import remain the way to back up and restore your library. The extra undo and snapshot restore controls have been removed from Settings to keep it focused.

A better first start

First-time installs begin with 12 starter favorites: Google, Gmail, Google Drive, Claude, ChatGPT, Gemini, the 1stTab website, YouTube, YouTube Music, Google Calendar, DuckDuckGo, and Brave.

The starter list skips duplicate URLs and preserves existing bookmarks. Updates do not add the starter list again. This release also fixes missing website icons and improves their fallback when an icon cannot load.

Keep the feedback coming

These changes come from using the library and refining the small details. If you spot a problem, report a bug. Have an idea for the next update? Suggest a feature.
