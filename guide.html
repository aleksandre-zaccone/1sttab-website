About this guide

This guide covers the current 1stTab bookmark workspace. Version 2.2.2 adds a localized update notice to the multilingual interface; optional Google Drive backup and restore were introduced in version 2.2.1. Get the latest version from the Chrome Web Store.

Your library, one tab away

Open a new Chrome tab to see Favorites in grid view. The number of bookmarks per row adapts to the available width. Chrome may ask you to confirm the new-tab change after installing or reloading 1stTab. Your library uses Chrome’s native bookmarks, so changes also appear in Chrome’s bookmark manager.

  1. Save a page. Click the extension’s toolbar icon on a normal website, or choose Add bookmark in your library.
  2. Give it context. Pick a folder from the hierarchical dropdown, add comma-separated tags, and write an optional note.
  3. Find it again. Search its title, URL, tags, or note. Click the bookmark title to open the website.
The design previews contain sample bookmarks. Those preview samples are separate from the 12 starter bookmarks added as Favorites on first install. Existing bookmarks are preserved, duplicate URLs are skipped, and updates do not add the starter list again.

Folders & drag and drop

Use New collection to create a folder. The + on a tree row creates a subfolder; the pencil renames it and the trash icon opens a deletion preview. Deleting a folder also deletes its contents after confirmation. Chrome roots and managed bookmarks are protected.

Drag a bookmark onto a folder to move it immediately. Select several bookmarks first to move them together. Drag between bookmarks in the same folder to save a new manual order. Name A–Z and Newest first change only the displayed order.

For keyboard or touch use, select bookmarks and choose Move selected. The selection bar also offers bulk tagging and deletion.

Drag the right edge of the folder sidebar to resize it. Double-click the edge to reset its width. With the divider focused, use Left/Right arrows for 10-pixel steps, Shift + arrow for 50, or Home/End for the minimum/maximum. Width is remembered on this device. On small screens the Collections button opens a drawer.

Search & filters

Search stays at the top while you scroll. Press Ctrl / ⌘ + K to focus it.

Show filters reveals collection, tag, domain, and favorites filters in both card and list views. Hiding the filters keeps them applied; a badge shows the active count. Use Reset filters to clear them and search. Clicking a tag filters by that tag.

Bookmarks show the website’s icon. Most starter sites use bundled high-resolution icons; other sites use Chrome’s saved favicon or request the site’s favicon when needed. If neither is available, the first letter of the name is shown. Use the star on a bookmark to add it to Favorites. Select Favorites in the sidebar to see your saved favorites. On smaller screens, open Collections to access the sidebar.

Make it yours

The gear beside search opens the separate Settings page. Changes save automatically. Back to library returns to your current folder, search, and selections during the same session.

  • Appearance: choose Prism, Atelier, Studio, Pop, or Enterprise, with Light, Dark, or Follow system mode.
  • Text & icons: increase text up to 140% and icons up to 150% independently.
  • Workspace: choose cards or a compact list, display sort, spacing, note visibility, and reduced motion.
  • Card shapes: Rectangle, Square, Rounded, Circle, or Sphere. Circle and Sphere show a large bookmark icon first, the name beneath it, and the favorite star below. Use Preview in card view to try the shape. List view stays compact.

Reset appearance restores the default theme, sizes, card shape, sidebar width, spacing, notes, and motion preferences. It keeps your bookmarks, selected view, sort order, and expanded folders.

Interface language

In Settings → Language, choose a language or leave it on Automatic to follow your browser language. The interface supports English, Russian, Georgian, German, and Japanese. The 2.2.2 update notice uses the same five languages. Your language choice is stored on this device and does not translate bookmark titles, folders, notes, tags, or URLs.

Export, import & cleanup

Open Settings → Library tools.

  • Export library downloads a JSON backup of bookmarks, tags, and notes. It does not include API keys.
  • Import validates a 1stTab JSON file, shows counts, and asks you to choose a destination. Confirming adds folders and bookmarks directly to your chosen destination without overwriting existing bookmarks.
  • Clean duplicates lists exact-URL duplicates and empty folders. Choose items, review the deletion, then confirm. Nothing is deleted automatically.

Backup & restore

Use Export library before extensive changes. To restore an exported JSON file, choose Import, review the preview, and select a destination. In version 2.2.1, you can also connect Google Drive and start a manual backup. Review a Drive snapshot and its additive restore preview before confirming; restore can create duplicates and does not overwrite existing bookmarks.

Keyboard & side panel

Control Action
Ctrl / ⌘ + K Focus bookmark search, returning from Settings if necessary.
Alt + Shift + P Open the side panel (Chrome shortcut settings may override this).
Escape Dismiss a dialog or close the mobile folder drawer.
Tab / Shift + Tab Move through buttons, inputs, and the sidebar divider.

The side panel, new-tab manager, and Settings share bookmarks and local preferences. Settings is a page; it is not dismissed with Escape.

Data & future sync

The local library requires no account. Native bookmarks follow Chrome’s own sync settings. Tags, notes, favorites, settings, and recovery snapshots stay on this device unless you explicitly include them in a manual Drive backup.

Version 2.2.1 offers user-started Google Drive backup and additive restore, not automatic or continuous sync. Scheduled backups and cross-account sync remain future proposals. See the roadmap and Privacy page for details about data handling.
